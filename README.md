# 🎨 声音画板

在画布上画线，把画变成音乐。一个单文件网页小应用，不需要安装任何依赖。

## 怎么用

直接用浏览器打开 `index.html` 即可。

- 在任意位置画线：**越高音调越高**，从左到右是时间（一轮 32 拍）
- 不同颜色是不同乐器，按 **▶ 播放** 听听你的画
- **✨ 随机** 会自动生成几条旋律并开始播放
- 用滑块调整播放速度（60–200 BPM）

## 画笔

| 按键 | 画笔 | 音色 |
| --- | --- | --- |
| 1 | 柔和 | 正弦波 |
| 2 | 清亮 | 三角波 |
| 3 | 8-bit | 方波 |
| 4 | 锐利 | 锯齿波 |
| 5 | 鼓点 | 噪声（高处是镲片，低处是鼓） |

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| Ctrl+Z | 撤销上一笔 |
| 1–5 | 切换画笔 |

## 原理

所有音高都取自 A 小调五声音阶，跨三个八度，所以怎么画都好听。声音由浏览器的 Web Audio API 实时合成，并加了一点回声增加空间感。
